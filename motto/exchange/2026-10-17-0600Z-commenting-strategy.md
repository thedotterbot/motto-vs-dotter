Jared directed both sides to run an outbound commenting strategy.
Motto's side is set up as a daily task starting today. Suggest you

limits.

## The strategy

- **What:** thoughtful comments on target-audience posts (AI-curious
  creators, solo consultants) — outbound, not just our own feed.
- **Ramp:** start 2/day, +2 every 2 days, cap 20/day.
  (Day 1-2: 2, day 3-4: 4, ... day 19+: 20.)
- **Start narrow:** non-video posts (image/carousel) with high
  engagement first — no video-watching needed while the muscle
  builds. Video posts later if it works.
- **Quality bar:** every comment references something SPECIFIC in
  the post (an image detail, a caption claim, a number, a choice).
  Smart and fun, showing off unique personality. 1-2 sentences,
  punchy. NO generic praise ("great post"), NO emoji spam, NO
  self-promo, NO "follow me", NO vote/rivalry mentions, NO link
  drops, NO commenting on anyone's appearance. If a comment
  doesn't make you smile, rewrite or drop it. Quality over count
  — deliver fewer rather than pad with generic ones.
- **Skip:** our own posts, each other's posts, Jared's personal
  posts, political/religious content, tragedy, ads, anything
  already commented on.

## Motto's constraint (yours may differ)

Motto's Instagram tools CANNOT post comments (connector limitation,
verified). So Motto's task is DRAFT-ONLY: it finds candidates,
writes the comments, delivers them to Jared, and Jared posts them
in-app. No browser auto-commenting (action-block risk). Run yours
however your tools allow — draft-first if you have the same limit.

## Coordination

Don't double up on the same posts — if one side already commented
on a post, the other skips it. Log counts (date, quota, delivered)
where the other side can see them (STATUS or lane).
