rivalry. Either side adds entries; never edit the other's entries.
Rules: resources only, analysis in our own words, no copied text.

## 2026-10-16 — Opus video prompt repo (davidiya.co)

- Source: https://www.instagram.com/reel/Dee1BaaH71-/ (shared by Jared)
- What it offers: a repo of videos people made with Opus 5.5
  that already took off, with the prompt behind most of them.
  Pitch: pick ones matching your niche, copy the prompt, start
  from something that already proved it can hold attention.
- What we'd use: prompt starting points, not prompt copies.
  A prompt that worked for someone else's niche/format does not
  transfer to a plush character rivalry reel. The transferable
  piece is the structure of prompts that held attention, not
  the prompts themselves.
- Caveats: comment-bait funnel ("Comment VIDEO and I'll send
  you the repo link"). Video content not fully watched — this
  note is from the caption + post metadata. "Proven" means it
  took off for someone else, not that it works for us.
- Status: NOT adopted. No pipeline test yet.

## 2026-10-16 — Claude Code + 20 repos for prompt-to-motion (msbintel)

- Source: https://www.instagram.com/reel/DehV8xeDXcC/ (shared by Jared)
- What it offers: "With Claude Code and the right GitHub repos,
  you describe the animation in plain words and export the
  video." 20 repos, including Remotion, positioned as an After
  Effects alternative. Tags name GSAP explicitly.
- What we'd use: the idea is adjacent to our pipeline — we
  already do code-to-video (HyperFrames: HTML/JS → MP4), and
  Remotion is a real code-to-video framework (React → video)
  worth evaluating against HyperFrames on one concrete axis:
  does it make acting/iteration faster, or just different?
  The 20 repos themselves are unverified until seen.
- Caveats: comment-bait funnel ("Comment MOTION and I'll send
  you all 20 repos"). "Describe in plain words, export video"
  is a pitch, not a measured claim — prompt-to-motion still
  needs art direction, timing, and QA, which is where our
  loop lives. Video content not fully watched — this note is
  from the caption + post metadata.
- Status: NOT adopted. Remotion evaluation queued (post-reset).
