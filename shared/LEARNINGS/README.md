# Shared Learnings from Examples

Both sides study public videos and log what they learn HERE — one
entry per video, in our own words. This is the shared notebook for
content craft: why a video works, not just what funnel it runs.

## Rules

- Public examples only. No unreleased jokes, no scripts, no
  private methods, no credentials. (Lane rules still apply.)
- Analysis in your own words. Quote briefly or not at all — never
  reproduce someone else's script, skill, or caption text at
  length. If a source has no clear license, summarize; do not copy.
- Every entry needs: the video (link + creator + date observed),
  TAGS, what works and why, what does NOT transfer to us, and one
  thing we will apply. A link without the why is useless.
- "Applies to us" must name something concrete: a panel check, a
  script rule, a production rule, or a pack decision. Vague
  inspiration does not count.
- Do NOT copy the example's content, framework, phrasing, or
  jokes. Steal the mechanism, never the material. If a future
  script of ours resembles an example logged here, that is a
  fail, not a find.
- One file per video: `entries/YYYY-MM-DD-<slug>.md`. Either side
  adds files; do not edit the other side's entries. Disagree in
  your own entry or in the lane, not by rewriting theirs.

## Tag taxonomy

Use these tags so entries stay searchable. Add a new tag only when
none fits, and define it here when you do.

- Format: `format:talking-head`, `format:character`,
  `format:screen-share`, `format:mixed`
- Hook: `hook:cold-open`, `hook:confession`, `hook:question`,
  `hook:visual-gag`, `hook:claim`
- Structure: `structure:one-premise`, `structure:escalating-list`,
  `structure:storytime`, `structure:tutorial-twist`,
  `structure:demo-walkthrough` (straight demo: show each step
  producing an output, no twist), `structure:reaction`,
  `structure:lore-drop`
- Engine: `loop:open-question`, `loop:payoff-chain`,
  `proof:screenshot`, `proof:metrics`, `proof:demonstration`,
  `proof:testimonial`, `proof:none` (claims with no evidence
  shown — a cautionary pattern, not a technique), `character:one-bit`, `character:feud`,
  `character:catchphrase`
- Pacing: `pacing:fast-cuts`, `pacing:long-take`,
  `pacing:line-by-line`
- Comedy: `comedy:physical`, `comedy:roast`, `comedy:absurd`,
  `comedy:self-aware`, `comedy:dark`
- Funnel: `funnel:comment-keyword`, `funnel:link-in-bio`,
  `funnel:newsletter`, `funnel:none`
- Verdict: `verdict:study`, `verdict:cautionary`, `verdict:do-not-copy`
